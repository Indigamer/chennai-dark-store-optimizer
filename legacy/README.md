# Preserved Legacy Prototype Files

These files contain the original Cartesian planar prototype from the initial project phase. They are preserved for reference and historical integrity:

- `Dark store.py`: The original standalone script utilizing Cartesian $(x,y)$ coordinate math and static Matplotlib visualization.
- `dark_store_customers.csv`: Synthetic customer data with planar `x,y` columns (non-geographic).
- `dark_store_stores.csv`: Candidate store data with planar `x,y` columns (non-geographic).

The production geographic Chennai application is driven by `app.py`, `optimization_model.py`, `routing_provider.py`, and `data_validation.py` in the root folder.
